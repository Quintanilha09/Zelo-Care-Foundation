## Prompt pronto para o Replit Agent

```
## Contexto
Leia replit.md. Esta tarefa fecha a linguagem visual antes de qualquer tela real existir,
para nenhuma tela futura virar negociação de estilo.

## O que construir
- Tokens semânticos no Tailwind, não cor crua:
  - `calm` (verde #059669) — tudo em dia
  - `attention` (âmbar #F59E0B) — dose perdida, estoque baixo
  - `neutral`
  - `danger` — reservado exclusivamente para ação destrutiva (excluir paciente, revogar
    acesso). NUNCA para estado de dose.
- Escala tipográfica com base 18px. Corpo de texto mínimo 16px
- Alvo de toque mínimo 48x48px em todo elemento clicável
- Componentes: Button (primária/secundária/destrutiva), Card, DoseCard, StatusBanner,
  Avatar (iniciais), Sheet (bottom sheet mobile), EmptyState, Skeleton, Toast
- Radix UI apenas para primitivas acessíveis (dialog, popover) — nada além disso
- Layout mobile-first: largura máxima de conteúdo, navegação inferior, área segura (safe
  area) respeitada
- Contraste mínimo AA (4.5:1) nos pares de token. Foco visível em navegação por teclado
- Página `/dev/design` renderizando todos os componentes em todos os estados (normal,
  carregando, desabilitado, erro) — vira a referência visual do projeto

## Decisões já tomadas — não reabrir
Sem biblioteca de componentes pronta (Material UI, Chakra, etc.). Componentes próprios
sobre Tailwind, Radix só para primitivas.

## Critérios de aceite
- `/dev/design` mostra todos os componentes nos 4 estados
- Nenhum vermelho aparece em nenhum estado de dose em nenhum componente
- Teste automatizado de contraste nos pares de token principais

## NÃO faça nesta sessão
Nenhuma tela real do produto. Nenhuma chamada de API. Nenhum dado real.

## Antes de codar
Me responda em 3-5 linhas: o que vai construir, que decisão está tomando, e o que precisa
de mim. Não escreva código até eu confirmar.
```

## Verificação
- [ ] `/dev/design` acessível e mostra os 9 componentes listados
- [ ] Nenhum uso de vermelho em contexto de dose — inspeção visual + grep por classe de cor
- [ ] Teste de contraste automatizado passa
- [ ] Alvo de toque ≥ 48px verificado nos componentes interativos

## Condição de pronto
Todos os itens de verificação passam. `danger` só aparece em contexto de ação destrutiva, nunca de dose.
