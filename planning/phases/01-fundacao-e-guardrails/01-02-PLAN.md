## Prompt pronto para o Replit Agent

```
## Contexto
Leia replit.md antes de tudo — ele define stack, pastas e invariantes. Esta tarefa cria o
esqueleto rodando, sem nenhuma feature de usuário.

## O que construir
- TypeScript estrito em todo o repositório (`strict: true`, sem `any` implícito)
- `/server`: Express + TypeScript. Pastas com `index.ts` de barril:
  `modules/{identity,patient,caregiving,treatment,scheduling,adherence,inventory,
  appointments,notifications,reports,billing}` e `shared/{db,events,audit,logger,clock}`
- `/client`: React + Vite + TypeScript + Tailwind, PWA instalável via vite-plugin-pwa
  (manifest, ícones, service worker registrado — sem lógica de push ainda)
- `/shared`: tipos e schemas Zod compartilhados entre cliente e servidor. Toda entrada de
  API validada por Zod
- Drizzle ORM apontando para o Postgres do Replit (via DATABASE_URL), migrations
  versionadas em arquivo — nunca `drizzle-kit push` em produção
- Barramento de eventos de domínio em memória em `shared/events`, tipado, com os eventos
  já declarados como tipos (sem handler ainda): DoseScheduled, DoseTaken, DoseMissed,
  EscalationTriggered, StockLow, CaregiverJoined
- Logger Pino em `shared/logger` com `redact` configurado por allowlist: qualquer campo
  fora da lista permitida vira `[REDACTED]`
- `GET /health` devolvendo status do processo e do banco
- Segredos via Replit Secrets. `.env.example` documentando cada chave, sem valor real
- Vitest configurado, com um teste de exemplo passando

## Decisões já tomadas — não reabrir
- Vitest para testes (não Jest)
- Pino para log (não Winston), redação por allowlist
- vite-plugin-pwa para o boilerplate do PWA

## Critérios de aceite
- `npm run dev` sobe cliente e servidor juntos; `/health` responde 200 com banco conectado
- Teste automatizado prova que o logger redige um objeto contendo `medicationName` e
  `patientId` — a saída não contém esses valores
- Uma migration inicial (mesmo vazia) roda e reverte sem erro
- Build de produção passa sem warning de TypeScript

## NÃO faça nesta sessão
- Nenhuma tabela de domínio — é a próxima story (01-04)
- Nenhuma tela real, nenhuma autenticação, nenhuma fila
- Não instale biblioteca de UI pronta — o design system tem story própria (01-03) com
  regra específica de não usar biblioteca pesada

## Antes de codar
Me responda em 3-5 linhas: o que vai construir, que decisão técnica está tomando, e o que
precisa de mim. Não escreva código até eu confirmar.
```
