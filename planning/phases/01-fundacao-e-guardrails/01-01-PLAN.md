## Prompt pronto para o Replit Agent

```
## Contexto
Você vai criar o arquivo que lê em toda sessão futura deste projeto — a constituição do
ZELO. Não escreva código de aplicação nesta tarefa: o entregável é documentação que evita
retrabalho em todas as próximas 41 histórias.

## O que construir
1. Criar `replit.md` na raiz com:
   - O produto em 3 linhas (cuidado compartilhado: remédio, consulta e rotina; a família
     inteira vê que foi feito)
   - Stack fechada: React + Vite + TS + Tailwind (PWA) / Express + TS / Postgres + Drizzle /
     pg-boss / Web Push VAPID / SSE / Claude Vision
   - Mapa de pastas de /server/modules: identity, patient, caregiving, treatment,
     scheduling, adherence, inventory, appointments, notifications, reports, billing
   - Padrão de nomeação de arquivos e módulos

2. Seção "Invariantes" — nunca violar, sem pedir confirmação:
   - Doses sempre persistidas no banco, nunca só em memória
   - Todo acesso a paciente valida vínculo do cuidador no servidor — nunca confiar em id
     vindo do cliente
   - Logs jamais contêm nome de medicamento, condição ou identificador de paciente
   - O app não prescreve, não calcula dose, não interpreta aferição, não checa interação
     medicamentosa

3. Seção "Tom":
   - Dose perdida é âmbar #F59E0B, jamais vermelho
   - Verde #059669 só para "tudo em dia"
   - Nunca culpar o cuidador em nenhum texto de interface

4. Seção "Protocolo de trabalho":
   - Uma story por vez
   - Antes de codar, resumir o plano em 3-5 linhas
   - Não refatorar arquivo fora do escopo da story
   - Não instalar dependência nova sem justificar em uma linha

5. Seção "Comandos": como rodar dev, testes e migrations (preencher conforme forem
   criados nas próximas stories — pode deixar placeholder marcado aqui)

6. Criar `docs/decisoes.md` com as 4 decisões de plataforma (PWA-first, pg-boss, Claude
   Vision, cobrança web), cada uma com a alternativa descartada e o motivo.

## Decisões já tomadas — não reabrir
As 4 decisões de plataforma acima são finais. Não proponha React Native, Redis/BullMQ,
OCR de terceiro ou in-app purchase.

## Critérios de aceite
- replit.md existe, tem menos de 200 linhas, nenhuma seção genérica
- Um leitor novo sabe, só com esse arquivo, onde colocar um módulo novo
- docs/decisoes.md registra decisão + alternativa descartada + motivo, para as 4 decisões

## NÃO faça nesta sessão
Nenhum código de aplicação. Nenhuma dependência instalada. Nenhum scaffold — isso é a
próxima story (01-02).

## Antes de codar
Me responda em 3-5 linhas: o que vai construir, que decisão está tomando, e o que precisa
de mim. Não escreva nada até eu confirmar.
```
